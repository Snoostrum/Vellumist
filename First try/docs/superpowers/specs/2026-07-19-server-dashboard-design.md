# 云服务器 Dashboard 页面 — 设计文档

> 2026-07-19 · 状态：待实现

## 目标

为 Ubuntu 云服务器做一个暗色主题 Dashboard 风格的前端页面，替换 Nginx 默认欢迎页。页面独立于后端运行，同时预留 Spring Boot API 接口，后端就绪后自动联动。

## 受众

一个人使用 — 自己访问自己的服务器时看到的「门面」，不需要登录、多用户等复杂功能。

## 技术决策

- **纯静态前端**：HTML + CSS + JS，结构/样式/交互三者分离
- **Nginx 托管前端，反向代理后端**：`/` 走静态文件，`/api/*` 代理到 Spring Boot
- **暗色主题**：控制台/终端风格，符合服务器管理场景
- **渐进增强**：后端不可用时页面正常展示（显示"离线"状态），不通不崩

### 各区域说明

| 区域 | 后端未通时 | 后端连通时 |
|------|-----------|-----------|
| 服务器状态卡片 | 显示"离线"，灰色 | 显示运行时长，绿色 |
| API 状态卡片 | 显示"开发中"，黄色 | 显示接口数量，绿色 |
| 资源卡片 | 显示 "--" | 显示 CPU/内存百分比 |
| 项目列表 | 显示占位示例项目 | 从 `/api/projects` 动态渲染 |
| 技能标签 | 静态展示 | 静态展示（无需后端） |

## API 端点设计（预留）

| 方法 | 路径 | 说明 | 前端使用 |
|------|------|------|---------|
| GET | `/api/health` | 健康检查 | 服务器状态卡片 |
| GET | `/api/info` | 服务器资源信息 | 资源卡片 |
| GET | `/api/projects` | 项目列表 | 项目卡片区 |

后端未实现时，`fetch()` 失败 → 进入离线降级模式，不影响页面渲染。

## 侧边栏导航

- 概览（默认选中）— 显示状态卡片 + 项目列表
- 项目 — 项目卡片全览
- 技能 — 技术栈标签云 + 学习路线
- API 状态 — 详细的接口调用状态面板

切换通过 JS 控制内容区显示/隐藏，不刷新页面。

## 前后端协作方式

1. 页面加载 → JS 立即渲染静态内容（技能标签、占位项目等）
2. 同时发起 `GET /api/health` → 成功则更新状态卡片为绿色，失败则保持灰色"离线"
3. 每 30 秒轮询一次 `/api/health`
4. 后端就绪后，逐步替换占位内容为真实数据
